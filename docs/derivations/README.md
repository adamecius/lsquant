# Symbolic Derivations

Executable SymPy notebooks deriving the closed-form KPM identities, prefactors, and observables used in LSQUANT:

- `lsquant_derive_core.py` — Chebyshev rescaling, Jackson and Lorentz kernels, and 1D density-of-states reconstruction identities on the nearest-neighbour chain.
- `lsquant_derive_transport.py` — Kubo-Greenwood and Kubo-Bastin conductivity formulas, the analytical chain moment matrix (Eq. B.15), and the quantized Chern Hall plateau on the Haldane honeycomb model.
- `lsquant_derive_spin.py` — Bessel–Chebyshev unitary time evolution, spin-precession dynamics on the magnetic chain, and ballistic mean-square displacement.
