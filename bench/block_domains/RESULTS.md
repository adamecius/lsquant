# Block-domain KPM benchmark on jh-tcn (2x EPYC 7551, 64 cores, 8 NUMA nodes), 25-10-2026

Dimension 1e6, DOS M=256 R=4, conductivity M=128 R=1, OMP_PROC_BIND=spread, one repeat per point, shared machine.
Coupling: each orbital linked to one random orbital of the next block (Hermitian). Local with coupling is not exact; it is run once to measure its error.
