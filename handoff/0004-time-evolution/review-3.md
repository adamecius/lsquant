# Handoff 0004 — review 3 (Fable to Agi): a stage-3 defect found in the field

While using the library on a real material (SIESTA and Wannier spin Hall runs with
non-centred spectral windows) the energy axis of every rank-2 reconstruction came out
shifted. Cause, in `python/lsquant/reconstruct.py`: the five Kubo formulas
(`kubo_greenwood`, `kubo_bastin`, `kubo_bastin_sea`, `kubo_bastin_surf`, `kubo_fft_grid`)
map the Chebyshev grid with

    energies[i] = x_grid[i] / scale + shift

where `shift = window.shift` is the dimensionless rescale shift `-Center/HalfWidth`, not an
energy. The inverse of `x = Scale * E + Shift` is `E = (x - Shift) / Scale = x * HalfWidth +
Center`; `dos_curve` already does `x * hw + bc` and is right. The defect is invisible to
the stage-0 goldens because every golden window is centred (`Shift = 0`), and it is not a
legacy defect: the legacy maps `x = (E - BandCenter) / HalfWidth`.

One item; nothing else is to be touched.

1. In the five formulas replace the mapping by `energies[i] = (x_grid[i] - shift) / scale`
   (that exact expression, so the centred case stays byte-identical: with `shift == 0.0`
   it is `x_grid[i] / scale` as before; do not rewrite it as `x * hw + center`, which
   rounds differently). Fix the docstrings that state the wrong formula (lines 42 and 175
   and the ones like them). Run the stage-3 self-check: nothing moves because all its
   windows are centred. Then run `stage3_kubo` form 2 on `goldens/stage0/graphene/operators`
   with `--window -3.5 2.5` (off-centre on purpose), `--formula bastin --broadening-meV 10`,
   exact trace, `M = 128`, and show in the report that the first and last energies of the
   curve are `-3.5 * 0.95 ... 2.5 * 0.95`-like values inside `[-3.5, 2.5]`, not outside.

The tester adds, at closure, a golden with that off-centre window generated by the legacy
binaries (G4c: graphene, `BOUNDS` file `-3.5 2.5`, moments and Bastin curve) so the gate
covers `Shift != 0` from now on; Fable records the defect in AGENTS.md section 10.

off-centre run on TCN, paste into `report.md`, commit. Do not push.
